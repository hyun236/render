# Tab Studio AI Chord Server (Hugging Face Spaces)
1. Hugging Face(huggingface.co)에서 **New Space → Docker (Blank)**를 만듭니다.
2. 이 압축 파일의 `Dockerfile`, `requirements.txt`, `app.py`, `README.md`를 업로드합니다.
3. 빌드가 끝나면 생성된 Space 주소(예: `https://아이디-space이름.hf.space`)를 타브 악보 앱의 **영상 → AI 서버 주소** 칸에 붙여넣으면 유튜브 링크에서 자동으로 코드를 추출합니다!
